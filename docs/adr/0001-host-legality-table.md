# Host-action legality is one shared table of refusal codes

`refuses` in `shared/legality.ts` is the one answer to "may the host send this action in this room", read by the server's `applyHostAction` and by every host control, so a live button the server ignores, or a greyed one it would accept, cannot drift in silently; `server/state.test.ts` sweeps every action in a spread of rooms and holds both directions. A refusal is a code, one per reason, and its sentence for the host is `REFUSAL_TEXT`. The table rules on the round, never on a payload: hints about what a press would achieve (closing a duel window that would seat nobody) and checks on a form's own contents stay in the surface as advice, because they are not legality and `shared/` may not import their helpers. `next`, `resetRound` and `cancelDuel` are never refused, since they are how a host gets out of a stuck question or duel.

Where: `shared/legality.ts` (`refuses`, `Refusal`), `client/ui.ts` (`REFUSAL_TEXT`), `server/state.ts` (`applyHostAction`), `server/state.test.ts`, `client/DuelPanel.tsx` (`closeBlockReason`)
