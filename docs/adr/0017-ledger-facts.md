# What the night's ledger records

- A verdict carries `reactionMs` only when the leader's stamp is after the arm. A steal pins its buzz to the arm and an early stamp is clamped to it, so neither is a reaction worth a card.
- On a closest question every paid player gets a verdict fact, but only the nearest is a hit: a half-paid second keeps its points but counts as a miss and never builds a streak.
- A standings fact is recorded when the key order changes or when first place changes between shared and outright. A tie at the top becoming one name is invisible in the order alone, because roster order already put that name first.
- Standings are tagged with the question or match only when play moved the scores. Host corrections, kicks and regroupings still record standings, so later comebacks are measured truthfully, but they are nobody's moment and never produce a milestone.

Where: `server/ledger.ts` (`nightFacts`, `heldOutright`)
