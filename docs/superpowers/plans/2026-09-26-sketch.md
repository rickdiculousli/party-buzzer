# Sketch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A skribbl-style drawing race as a fourth minigame: one player draws a word on their phone, it appears live on the board, everyone else types guesses, and faster correct guesses score more.

**Architecture:** An untimed minigame in `server/minigames/sketch/` behind the existing `MinigameDefinition` contract, built like Phantom Ink: a pure tick-counted world (`world.ts`), guess matching (`match.ts`), a word loader (`words.ts`), and a definition that projects board and phone frames. The client gets a board and phone surface plus a pure `sketchCues` function that turns frame changes into placeholder audio cues. No runtime or framework changes.

**Tech Stack:** Node (type stripping, `.ts` imports), Preact, `node:test`, Web Audio recipes in `client/cues.ts`.

**Spec:** `docs/superpowers/specs/2026-09-26-sketch-design.md`

## Global Constraints

- Server TypeScript runs through Node type stripping: no enums, no constructor parameter properties, relative imports end in `.ts`.
- No new dependencies.
- Canon words (`docs/design.md` §9): a **match** is one minigame start-to-results cycle; a **guess** is a typed answer; the **drawer** is the player drawing this turn. Never call a Sketch turn a "round" or a "question".
- Room cues play on the board only; private cues play only on the phone they belong to.
- Colour: guess times are measurement (`--cyan`); names, words and verdicts are drama (warm tokens).
- Timing constants: 50 ms steps, choose 10 s, reveal 5 s, draw time from `drawSec` (default 80, 30–180), `drawers` (default 0 = everyone, 0–30), feed of 8 wrong guesses, `sketch-miss` throttled to one per 120 ms, guesses at most 40 characters.
- Scoring: guesser `50 + round(50 × remainingTicks / drawTicks)`; drawer `round(100 × correct / (participants − 1))` per turn.
- Tests stay light (AGENTS.md): pure logic only; UI and glue get none.
- Comments describe the code as it is, never its history.
- Commit messages follow the repo's style (`feat: <what now happens>`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Guess spelling** — "Ice Cream", "ice-cream" and "icecream" must all count for `ice cream`; "Café" must match `cafe`. Pinned in Task 2's `match.test.ts`.
2. **Late guesses** — a guess applied after the reveal starts (timer, pass, or all-guessed) must be refused and score nothing. Pinned in Task 3's test "the turn ends on timeout and on pass…".
3. **Absent drawer** — a drawer who never picks or never draws must not stall the match: choose times out onto the first word, the draw runs out, the next drawer comes up. Pinned in Task 3's tests for choose timeout and timeout end.
4. **Spectators and bad input** — a player outside the match, an empty guess, or a 41-character guess is refused without touching the turn. Pinned in Task 3's test "strangers, empty and overlong guesses are refused".
5. **A board that reloads mid-match** — its first frame must play no cues, and a trimmed feed must still cue a new wrong guess. Pinned in Task 4's `sketch.test.ts`.

- [ ] **Step 3: Write `match.ts`**

```ts
const LETTER = /[\p{L}\p{N}]/u

/** Case, accents, spaces and punctuation never decide a guess. */
export function normalize(text: string): string {
  return text.normalize('NFKD').replace(/\p{M}/gu, '').toLowerCase().replace(/[^\p{L}\p{N}]/gu, '')
}

export function isCorrect(guess: string, word: string): boolean {
  const g = normalize(guess)
  return g !== '' && g === normalize(word)
}

/** One edit away, on words long enough that "close" does not give the word away. */
export function isClose(guess: string, word: string): boolean {
  const w = normalize(word)
  return w.length >= 4 && distance(normalize(guess), w) === 1
}

/** Levenshtein distance. */
export function distance(a: string, b: string): number {
  let row = Array.from({ length: b.length + 1 }, (_, j) => j)
  for (let i = 1; i <= a.length; i++) {
    const next = [i]
    for (let j = 1; j <= b.length; j++) {
      next[j] = Math.min(row[j] + 1, next[j - 1] + 1, row[j - 1] + (a[i - 1] === b[j - 1] ? 0 : 1))
    }
    row = next
  }
  return row[b.length]
}

/** The positions blanks hide and hints reveal. */
export function letterIndexes(word: string): number[] {
  return [...word].flatMap((ch, i) => LETTER.test(ch) ? [i] : [])
}

export function blanks(word: string, revealed: number[]): string {
  return [...word].map((ch, i) => LETTER.test(ch) && !revealed.includes(i) ? '_' : ch).join('')
}
```

import { readFileSync } from 'node:fs'
import { fileURLToPath } from 'node:url'
import { normalize } from './match.ts'

export const SKETCH_WORDS_PATH = fileURLToPath(new URL('../../../packs/sketch-words.txt', import.meta.url))
/** Words offered to the drawer each turn. */
export const CHOICES = 3

/** One word or phrase per line; blank and `#` lines are skipped and repeats dropped. */
export function parseSketchWords(text: string): string[] {
  const seen = new Set<string>()
  const words: string[] = []
  for (const line of text.split(/\r?\n/)) {
    const word = line.trim().replace(/\s+/g, ' ')
    const key = normalize(word)
    if (word.startsWith('#') || !key || seen.has(key)) continue
    seen.add(key)
    words.push(word)
  }
  return words
}

export function loadSketchWords(path: string): string[] | null {
  try {
    return parseSketchWords(readFileSync(path, 'utf8'))
  } catch {
    return null
  }
}

  InkPoint, InkStrokeView, MinigameResult, PlayerId, SketchEnd, SketchInput, SketchMiss, SketchStep,

export const TICKS_PER_SEC = 1_000 / STEP_MS
export const CHOOSE_TICKS = 10 * TICKS_PER_SEC
export const REVEAL_TICKS = 5 * TICKS_PER_SEC
/** Wrong guesses kept for the board. */
export const FEED = 8
export const GUESS_MAX = 40

export type SketchCorrectEntry = { seq: number; player: PlayerId; at: number; tick: number }

export type SketchWorld = {
  rand: () => number
  tick: number
  drawTicks: number
  participants: PlayerId[]
  /** Drawers in turn order. */
  order: PlayerId[]
  /** Words not yet offered this match. */

  turn: number
  step: SketchStep
  /** Tick the current step ends. */

  /** Tick the current drawing started. */

  choices: string[]
  word: string | null
  revealed: number[]
  /** Ticks at which the remaining hints are due. */
  hintAt: number[]
  strokes: InkStrokeView[]
  strokesVersion: number
  sentVersion: number
  nextStrokesTick: number
  live: InkPoint[] | null
  inkOps: Record<PlayerId, number>
  misses: SketchMiss[]
  correct: SketchCorrectEntry[]
  guessSeq: number
  close: Record<PlayerId, number>
  end: SketchEnd | null
  scores: Record<PlayerId, number>
}

const OK: InputOutcome = { status: 'accepted' }
const NO: InputOutcome = { status: 'refused', reason: 'not-allowed' }
const INVALID: InputOutcome = { status: 'refused', reason: 'invalid' }

export function createSketchWorld(input: {
  rand: () => number
  words: string[]
  participants: PlayerId[]
  drawSec: number
  drawers: number
}): SketchWorld {
  const { rand, words, participants, drawSec, drawers } = input
  const order = shuffle(rand, participants)
  const w: SketchWorld = {
    rand, tick: 0, drawTicks: drawSec * TICKS_PER_SEC, participants,
    order: drawers > 0 ? order.slice(0, drawers) : order,
    deck: shuffle(rand, words),
    turn: 0, step: 'choosing', stepEnds: 0, drawStart: 0, choices: [], word: null, revealed: [], hintAt: [],
    strokes: [], strokesVersion: 0, sentVersion: 0, nextStrokesTick: 0, live: null, inkOps: {},
    misses: [], correct: [], guessSeq: 0, close: {}, end: null,
    scores: Object.fromEntries(participants.map((id) => [id, 0])),
  }
  beginTurn(w)
  return w
}

export const drawerOf = (w: SketchWorld): PlayerId | undefined => w.order[w.turn]

function beginTurn(w: SketchWorld): void {
  w.strokes = []
  w.strokesVersion++
  w.live = null
  w.misses = []
  w.correct = []
  w.close = {}
  w.revealed = []
  w.hintAt = []
  w.end = null
  w.word = null
  if (w.turn >= w.order.length) {
    w.step = 'over'
    w.choices = []
    return
  }
  w.choices = w.deck.splice(0, CHOICES)
  w.step = 'choosing'
  w.stepEnds = w.tick + CHOOSE_TICKS
}

function startDrawing(w: SketchWorld, word: string): void {
  w.word = word
  w.choices = []
  w.step = 'drawing'
  w.drawStart = w.tick
  w.stepEnds = w.tick + w.drawTicks
  w.hintAt = letterIndexes(word).length > 3
    ? [w.tick + Math.round(w.drawTicks / 2), w.tick + Math.round(w.drawTicks * 3 / 4)]
    : []
}

function endTurn(w: SketchWorld, end: SketchEnd): void {
  w.scores[drawerOf(w)!] += Math.round(100 * w.correct.length / (w.participants.length - 1))
  w.step = 'reveal'
  w.end = end
  w.live = null
  w.stepEnds = w.tick + REVEAL_TICKS
}

function revealHint(w: SketchWorld): void {
  const hidden = letterIndexes(w.word!).filter((i) => !w.revealed.includes(i))
  // A hint never gives away the last hidden letter.
  if (hidden.length > 1) w.revealed.push(hidden[Math.floor(w.rand() * hidden.length)])
}

export function stepSketch(w: SketchWorld): void {
  w.tick++
  if (w.step === 'choosing' && w.tick >= w.stepEnds) startDrawing(w, w.choices[0])
  else if (w.step === 'drawing') {
    while (w.hintAt.length && w.tick >= w.hintAt[0]) {
      w.hintAt.shift()
      revealHint(w)
    }
    if (w.tick >= w.stepEnds) endTurn(w, 'timeup')
  } else if (w.step === 'reveal' && w.tick >= w.stepEnds) {
    w.turn++
    beginTurn(w)
  }
}

function guess(w: SketchWorld, player: PlayerId, raw: string, at: number): InputOutcome {
  if (w.step !== 'drawing' || player === drawerOf(w) || w.correct.some((c) => c.player === player)) return NO
  const text = raw.trim().replace(/\s+/g, ' ')
  if (!text || text.length > GUESS_MAX) return INVALID
  const seq = ++w.guessSeq
  if (isCorrect(text, w.word!)) {
    w.scores[player] += 50 + Math.round(50 * Math.max(0, w.stepEnds - w.tick) / w.drawTicks)
    w.correct.push({ seq, player, at, tick: w.tick })
    if (w.correct.length === w.participants.length - 1) endTurn(w, 'all')
  } else if (isClose(text, w.word!)) {
    w.close[player] = (w.close[player] ?? 0) + 1
  } else {
    w.misses = [...w.misses, { seq, player, text }].slice(-FEED)
  }
  return OK
}

export function applySketch(w: SketchWorld, playerId: PlayerId, input: SketchInput): InputOutcome {
  if (!w.participants.includes(playerId)) return NO
  if (input.kind === 'stroke' || input.kind === 'undo' || input.kind === 'clear') {
    w.inkOps[playerId] = (w.inkOps[playerId] ?? 0) + 1
  }
  const drawer = playerId === drawerOf(w)
  const drawing = w.step === 'drawing' && drawer
  switch (input.kind) {
    case 'pickWord': {
      if (w.step !== 'choosing' || !drawer) return NO
      const word = w.choices[input.index]
      if (word === undefined) return INVALID
      startDrawing(w, word)
      return OK
    }
    case 'ink':
      if (!drawing || !validPoints(input.points)) return NO
      w.live = input.points.map(([x, y]) => quantizePoint(x, y))
      return OK
    case 'stroke':
      if (!drawing || !validPoints(input.points)) return NO
      w.strokes.push({ points: input.points.map(([x, y]) => quantizePoint(x, y)), author: playerId })
      w.live = null
      w.strokesVersion++
      return OK
    case 'undo':
      if (!drawing || !w.strokes.length) return NO
      w.strokes.pop()
      w.strokesVersion++
      return OK
    case 'clear':
      if (!drawing || !w.strokes.length) return NO
      w.strokes = []
      w.strokesVersion++
      return OK
    case 'pass':
      if (!drawing) return NO
      endTurn(w, 'pass')
      return OK
    case 'guess':
      return guess(w, playerId, input.text, input.at)
  }
  return NO
}

export const sketchFinished = (w: SketchWorld) => w.step === 'over'

export function sketchResults(w: SketchWorld): MinigameResult[] {
  return w.participants
    .map((playerId) => ({ playerId, points: w.scores[playerId], shots: 0 }))
    .sort((a, b) => b.points - a.points || (a.playerId < b.playerId ? -1 : 1))
}

```ts
import type { SketchEnd, SketchShared } from '../shared/protocol.ts'
import type { Cue } from './sound.ts'

/** A board or phone frame, as far as cues and wording need one. */
export type SketchView = SketchShared & { matchId: string; tick: number; serverTime: number; close?: number }

/** A burst of wrong guesses plays as a patter, not a wall. */
export const MISS_GAP_MS = 120
/** The draw's last seconds tick. */
const TICK_FROM = 5
const PLACE_RATE = 0.06
const END_CUE: Record<SketchEnd, Cue> = { all: 'sketch-all', timeup: 'sketch-timeup', pass: 'sketch-pass' }

export const secondsLeft = (endsAt: number, now: number) => Math.max(0, Math.ceil((endsAt - now) / 1000))
const hidden = (blanks: string) => blanks.split('_').length - 1
const newest = (list: { seq: number }[]) => Math.max(0, ...list.map((entry) => entry.seq))

/**
 * The cues one surface plays for the change from `prev` to `next`. `who` is
 * `'board'` or the phone's player id. A first frame, or one from another match,
 * only sets the baseline.
 */
export function sketchCues(prev: SketchView | null, next: SketchView, who: 'board' | string): { cue: Cue; rateScale?: number }[] {
  if (!prev || prev.matchId !== next.matchId) return []
  const board = who === 'board'
  const drawer = next.drawer === who
  // The countdown holds tick 0; the first turn starts with the first step.
  const turnStart = next.step === 'choosing' && (next.turn !== prev.turn || (prev.tick === 0 && next.tick > 0))
  const sameTurn = next.turn === prev.turn
  const out: { cue: Cue; rateScale?: number }[] = []

  if (turnStart && board) out.push({ cue: 'sketch-turn' })
  if (turnStart && drawer) out.push({ cue: 'sketch-yours' })
  if (!sameTurn) return out

  if (board && prev.step === 'choosing' && next.step === 'drawing') out.push({ cue: 'sketch-go' })
  if (board && newest(next.misses) > newest(prev.misses)) out.push({ cue: 'sketch-miss' })

  const top = newest(prev.correct)
  next.correct.forEach((entry, place) => {
    if (entry.seq <= top) return
    const rateScale = 1 + PLACE_RATE * place
    if (board || drawer) out.push({ cue: 'sketch-got', rateScale })
    else if (entry.player === who) out.push({ cue: 'sketch-right' })
  })

  if (!board && !drawer && (next.close ?? 0) > (prev.close ?? 0)) out.push({ cue: 'sketch-close' })
  if (!board) return out

  if (prev.step === 'drawing' && next.step === 'drawing') {
    if (prev.blanks && hidden(next.blanks) < hidden(prev.blanks)) out.push({ cue: 'sketch-hint' })
    const before = secondsLeft(prev.endsAt, prev.serverTime)
    const after = secondsLeft(next.endsAt, next.serverTime)
    if (after < before && after >= 1 && after <= TICK_FROM) out.push({ cue: 'sketch-tick' })
  }
  if (prev.step === 'drawing' && next.step === 'reveal' && next.end) out.push({ cue: END_CUE[next.end] })
  if (prev.step !== 'over' && next.step === 'over') out.push({ cue: 'sketch-over' })
  return out
}

export function stepLine(v: Pick<SketchShared, 'step' | 'drawer' | 'end'>, nameOf: (id: string) => string): string {
  switch (v.step) {
    case 'choosing': return `${nameOf(v.drawer)} is choosing a word`
    case 'drawing': return `${nameOf(v.drawer)} is drawing`
    case 'reveal': return v.end === 'pass' ? `${nameOf(v.drawer)} passed` : v.end === 'all' ? 'Everyone got it' : 'Time'
    case 'over': return 'Match over'
  }
}

export const fmtSeconds = (ms: number) => `+${(ms / 1000).toFixed(2)}s`

export function ordinal(n: number): string {
  const teen = n % 100 >= 11 && n % 100 <= 13
  const suffix = teen ? 'th' : ({ 1: 'st', 2: 'nd', 3: 'rd' } as Record<number, string>)[n % 10] ?? 'th'
  return `${n}${suffix}`
}
```

```ts
import { validPoints } from '../../../shared/protocol.ts'
import type { PlayerId, SketchCorrect, SketchPrivate, SketchShared } from '../../../shared/protocol.ts'
import type { Clock, MinigameDefinition } from '../definition.ts'
import { blanks } from './match.ts'
import { CHOICES, SKETCH_WORDS_PATH, loadSketchWords } from './words.ts'
import {
  STEP_MS, TICKS_PER_SEC, applySketch, createSketchWorld, drawerOf, sketchFinished, sketchResults, stepSketch,
  type SketchWorld,
} from './world.ts'

const DISCRETE = new Set(['pickWord', 'stroke', 'undo', 'clear', 'pass', 'guess'])

const sendsStrokes = (w: SketchWorld) => w.strokesVersion !== w.sentVersion || w.tick >= w.nextStrokesTick

/** Times come from each press, clamped to the drawing and to the step that took it. */
function correctView(w: SketchWorld, clock: Clock): SketchCorrect[] {
  const start = clock(w.drawStart * STEP_MS)
  return w.correct
    .map((c) => ({
      seq: c.seq,
      player: c.player,
      ms: Math.round(Math.min(clock((c.tick + 1) * STEP_MS), Math.max(start, c.at)) - start),
    }))
    .sort((a, b) => a.ms - b.ms || a.seq - b.seq)
}

function shared(w: SketchWorld, clock: Clock): SketchShared {
  const shown = w.step === 'reveal' || w.step === 'over'
  return {
    step: w.step,
    drawer: drawerOf(w) ?? w.order[w.order.length - 1],
    turn: Math.min(w.turn, w.order.length - 1),
    turns: w.order.length,
    blanks: w.word ? blanks(w.word, w.revealed) : '',
    ...(sendsStrokes(w) ? { strokes: w.strokes } : {}),
    live: w.live,
    endsAt: clock(w.stepEnds * STEP_MS),
    misses: w.misses,
    correct: correctView(w, clock),
    end: w.end,
    word: shown ? w.word : null,
  }
}

function personal(w: SketchWorld, playerId: PlayerId): (SketchPrivate & { word?: string | null }) | null {
  if (!w.participants.includes(playerId)) return null
  const drawer = drawerOf(w) === playerId
  const knows = (drawer && w.step === 'drawing') || w.correct.some((c) => c.player === playerId)
  return {
    choices: drawer && w.step === 'choosing' ? w.choices : [],
    close: w.close[playerId] ?? 0,
    inkOps: w.inkOps[playerId] ?? 0,
    ...(knows ? { word: w.word } : {}),
  }
}

export function makeSketch(load: () => string[] | null, rand: () => number = Math.random): MinigameDefinition<SketchWorld> {
  let words: string[] = []
  return {
    stepMs: STEP_MS,
    untimed: true,
    prepare() {
      const loaded = load()
      if (!loaded || loaded.length < CHOICES) return 'sketch-words'
      words = loaded
      return null
    },
    startable(_lobby, connected) {
      if (connected.length < 2) return 'too-few-players'
      // ponytail: sized for everyone drawing; the Drawers option only lowers the need.
      return words.length < CHOICES * connected.length ? 'sketch-words' : null
    },
    create(_seed, participants, options) {
      return { world: createSketchWorld({ rand, words, participants, drawSec: options.drawSec, drawers: options.drawers }) }
    },
    finished: sketchFinished,
    classify(input) {
      const i = input as { kind?: unknown; at?: unknown; points?: unknown; index?: unknown; text?: unknown } | null
      if (i?.kind === 'ink') return validPoints(i.points) ? 'continuous' : null
      if (typeof i?.kind !== 'string' || !DISCRETE.has(i.kind) || typeof i.at !== 'number' || !Number.isFinite(i.at)) return null
      if (i.kind === 'stroke' && !validPoints(i.points)) return null
      if (i.kind === 'pickWord' && !Number.isInteger(i.index)) return null
      if (i.kind === 'guess' && typeof i.text !== 'string') return null
      return 'discrete'
    },
    apply: (world, playerId, input) => applySketch(world, playerId, input),
    step: stepSketch,
    afterFrame(world) {
      if (!sendsStrokes(world)) return
      world.sentVersion = world.strokesVersion
      world.nextStrokesTick = world.tick + TICKS_PER_SEC
    },
    tick: (world) => world.tick,
    boardFrame: (world, clock) => shared(world, clock),
    playerFrame(world, playerId, clock) {
      const mine = personal(world, playerId)
      return mine && { ...shared(world, clock), ...mine }
    },
    results: sketchResults,
  }
}

export const sketch = makeSketch(() => loadSketchWords(SKETCH_WORDS_PATH))

import { useEffect, useRef, useState } from 'preact/hooks'
import { MAX_STROKE_POINTS, quantizePoint, type InkPoint, type InkStrokeView } from '../shared/protocol.ts'
import { DRAFT_MS, draftClear, draftStroke, draftUndo, liveDraft, strokePath, type InkDraft } from './ink.ts'
import { HoldButton } from './InkParts.tsx'
import { MISS_GAP_MS, sketchCues, type SketchView } from './sketch.ts'
import { play } from './sound.ts'

/** The drawing's shape everywhere it appears. */
const W = 400
const H = 300

/** Keeps the last strokes; frames carry them only when they changed and once a second. */
export function useSketchStrokes(frame: { matchId: string; strokes?: InkStrokeView[] } | null) {
  const strokes = useRef<InkStrokeView[] | null>(null)
  const match = useRef('')
  if (frame && match.current !== frame.matchId) {
    match.current = frame.matchId
    strokes.current = null
  }
  if (frame?.strokes) strokes.current = frame.strokes
  return strokes.current
}

/** Plays this surface's cues as frames arrive. `who` is 'board' or the phone's player id. */
export function useSketchCues(frame: SketchView | null, who: string | null) {
  const prev = useRef<SketchView | null>(null)
  const lastMiss = useRef(0)
  useEffect(() => {
    if (!frame || !who) return
    for (const { cue, rateScale } of sketchCues(prev.current, frame, who)) {
      if (cue === 'sketch-miss') {
        const now = performance.now()
        if (now - lastMiss.current < MISS_GAP_MS) continue
        lastMiss.current = now
      }
      play(cue, { rateScale })
    }
    prev.current = frame
  }, [frame, who])
}

export function SketchInk({ strokes, live, class: cls = '' }: { strokes: InkStrokeView[]; live: InkPoint[] | null; class?: string }) {
  return <svg class={`sketch-ink ${cls}`} viewBox={`0 0 ${W} ${H}`} aria-hidden="true">
    {strokes.map((stroke, i) => <path key={i} d={strokePath(stroke.points, W, H)} class="ink-stroke" />)}
    {live && <path d={strokePath(live, W, H)} class="ink-stroke is-live" />}
  </svg>
}

/**
 * The drawer's canvas. Sends the live stroke every 50 ms and commits on lift.
 * The phone shows its own draft until the server has processed every stroke,
 * undo and clear it sent.
 */
export function SketchCanvas({ strokes, author, processed, send, onPass }: {
  strokes: InkStrokeView[]
  author: string
  processed: number
  send: (input: { kind: 'ink'; points: InkPoint[] } | { kind: 'stroke'; points: InkPoint[] } | { kind: 'undo' } | { kind: 'clear' }) => void
  onPass: () => void
}) {
  const svg = useRef<SVGSVGElement>(null)
  const points = useRef<InkPoint[] | null>(null)
  const draft = useRef<InkDraft | null>(null)
  const lastSent = useRef(0)
  const [, redraw] = useState(0)
  draft.current = liveDraft(draft.current, processed, performance.now())
  const shown = draft.current?.strokes ?? strokes
  const server = { processed, strokes }

  const at = (event: PointerEvent): InkPoint => {
    const matrix = svg.current?.getScreenCTM()
    if (!matrix) return quantizePoint(0, 0)
    const point = new DOMPoint(event.clientX, event.clientY).matrixTransform(matrix.inverse())
    return quantizePoint(point.x / W, point.y / H)
  }
  const commit = (next: InkDraft, input: { kind: 'stroke'; points: InkPoint[] } | { kind: 'undo' } | { kind: 'clear' }) => {
    draft.current = next
    send(input)
    setTimeout(() => redraw((n) => n + 1), DRAFT_MS)
    redraw((n) => n + 1)
  }
  const finish = () => {
    const stroke = points.current?.slice(0, MAX_STROKE_POINTS)
    points.current = null
    if (stroke?.length) commit(draftStroke(draft.current, server, { points: stroke, author }, performance.now()), { kind: 'stroke', points: stroke })
    else redraw((n) => n + 1)
  }
  return <>
    <div
      class="sketch-canvas-area"
      onPointerDown={(event) => {
        ;(event.currentTarget as Element).setPointerCapture(event.pointerId)
        points.current = [at(event)]
        redraw((n) => n + 1)
      }}
      onPointerMove={(event) => {
        if (!points.current) return
        points.current.push(at(event))
        const moved = performance.now()
        if (moved - lastSent.current >= 50) {
          lastSent.current = moved
          send({ kind: 'ink', points: points.current.slice(0, MAX_STROKE_POINTS) })
        }
        redraw((n) => n + 1)
      }}
      onPointerUp={finish}
      onPointerCancel={finish}
    >
      <svg ref={svg} class="sketch-canvas" viewBox={`0 0 ${W} ${H}`}>
        {shown.map((stroke, i) => <path key={i} d={strokePath(stroke.points, W, H)} class="ink-stroke" />)}
        {points.current && <path d={strokePath(points.current, W, H)} class="ink-stroke is-live" />}
      </svg>
    </div>
    <div class="sketch-canvas__buttons">
      <button class="btn" disabled={!shown.length} onClick={() => commit(draftUndo(draft.current, server, performance.now()), { kind: 'undo' })}>Undo</button>
      <button class="btn" disabled={!shown.length} onClick={() => commit(draftClear(draft.current, server, performance.now()), { kind: 'clear' })}>Clear</button>
      <HoldButton label="Pass (hold)" onHeld={onPass} />
    </div>
  </>
}

    <SketchInk strokes={strokes} live={sketch.live} />
    {sketch.step === 'drawing' && !drawer && (place >= 0
      ? <p class="sketch-phone__got fx-pop">Got it · {ordinal(place + 1)} · <span class="sketch-got__ms">{fmtSeconds(sketch.correct[place].ms)}</span></p>
      : <form class="sketch-guess" onSubmit={(event) => {
          event.preventDefault()
          if (!text.trim()) return
          input({ kind: 'guess', text })
          setText('')
        }}>
          <input class="sketch-guess__field" value={text} maxLength={40} placeholder="Your guess"
            autocomplete="off" autocapitalize="off" enterkeyhint="send"
            onInput={(event) => setText((event.currentTarget as HTMLInputElement).value)} />
          <button class="btn btn--primary" type="submit">Send</button>
          <p class={`sketch-guess__close${flash ? '' : ' is-hidden'}`}>Close!</p>
        </form>)}
  </main>
}
```

**Interfaces:**

- [ ] **Step 1: Write the tool**

```ts
/**
 * Synthetic self-play for Sketch. Eight bots join and play one match: a drawer
 * picks a word and scribbles; guessers send wrong guesses, the odd close one,
 * and the right answer once their skill allows. Phones already in the room play
 * along. The log names each drawer and word.
 *
 *   npm run sim-sketch
 *   npm run sim-sketch -- 400                  one bot action every 0.4 s
 *   npm run sim-sketch -- 400 http://box:8080
 *
 * The match ends on its own; Ctrl-C ends it early. Either way the minigame
 * closes and the bots leave.
 */
import { setTimeout as sleep } from 'node:timers/promises'
import { connect, reachable } from './conn.ts'
import type { SketchInput } from '../shared/protocol.ts'

const args = process.argv.slice(2)
const TICK_MS = Number(args.find((arg) => /^\d+$/.test(arg)) ?? 600)
const URL = args.find((arg) => arg.startsWith('http')) ?? (await reachable())
const NAMES = ['Ada', 'Bo', 'Cy', 'Dee', 'Eli', 'Fay', 'Gus', 'Hal']
const WRONG = ['cat', 'house', 'a sad dog', 'PANCAKE', 'banana??', 'the moon', 'spaghetti', 'a potato', 'is that a horse', 'robot']
const RESULTS_MS = 8_000

const pick = <T>(items: T[]) => items[Math.floor(Math.random() * items.length)]
const scribble = () => {
  let x = 0.2 + Math.random() * 0.6
  let y = 0.2 + Math.random() * 0.6
  return Array.from({ length: 20 }, () => {
    x = Math.min(0.95, Math.max(0.05, x + (Math.random() - 0.5) * 0.12))
    y = Math.min(0.95, Math.max(0.05, y + (Math.random() - 0.5) * 0.12))
    return [x, y] as [number, number]
  })
}

const host = await connect(URL, 'host')
const bots = []
for (const [i, name] of NAMES.entries()) {
  const conn = await connect(URL, 'player', name, `sim-sketch-${name}`)
  // Sequence numbers start from the clock so a rerun never reuses remembered ones.
  // Skill is how many of this bot's actions into a drawing it can get the word.
  bots.push({ conn, name, seq: Date.now(), skill: 4 + i * 2 })
}

const stop = () => {
  host.send({ t: 'host', action: { a: 'cancelMinigame' } })
  host.send({ t: 'host', action: { a: 'closeMinigame' } })
  host.send({ t: 'host', action: { a: 'next' } })
  for (const bot of bots) {
    bot.conn.close()
    host.send({ t: 'host', action: { a: 'kick', playerId: bot.conn.playerId } })
  }
  console.log('Game closed, bots removed.')
  setTimeout(() => process.exit(0), 200)
}
process.on('SIGINT', stop)

host.send({ t: 'host', action: { a: 'cancelMinigame' } })
host.send({ t: 'host', action: { a: 'closeMinigame' } })
host.send({ t: 'host', action: { a: 'prepareMinigame', id: 'sketch', options: { drawSec: 45 } } })
await host.waitFor((s) => s.minigame?.id === 'sketch' && s.minigame.phase === 'ready')
host.send({ t: 'host', action: { a: 'startMinigame' } })
await host.waitFor((s) => s.minigame?.phase === 'playing', 10_000)
const matchId = host.state()!.minigame!.matchId

/** The sim cheats: a drawer bot's frame carries the word, so guessers can get it. */
const wordNow = () => {
  for (const bot of bots) {
    const frame = bot.conn.frame()
    if (frame?.role === 'player' && frame.id === 'sketch' && frame.drawer === bot.conn.playerId && frame.word) return frame.word
  }
  return null
}

let turn = -1
let actions = 0
while (host.state()?.minigame?.phase === 'playing') {
  const word = wordNow()
  for (const bot of bots) {
    const frame = bot.conn.frame()
    if (frame?.role !== 'player' || frame.id !== 'sketch' || frame.matchId !== matchId) continue
    const send = (input: { kind: string } & Record<string, unknown>) =>
      bot.conn.send({ t: 'minigameInput', matchId, seq: bot.seq++, input: { ...input, at: bot.conn.now() } as SketchInput })
    if (frame.turn !== turn) {
      turn = frame.turn
      actions = 0
    }
    const me = bot.conn.playerId
    if (frame.drawer === me) {
      if (frame.step === 'choosing' && frame.choices.length) {
        const index = Math.floor(Math.random() * frame.choices.length)
        console.log(`Turn ${frame.turn + 1}/${frame.turns}: ${bot.name} draws "${frame.choices[index]}"`)
        send({ kind: 'pickWord', index })
      } else if (frame.step === 'drawing') send({ kind: 'stroke', points: scribble() })
      continue
    }
    if (frame.step !== 'drawing' || frame.correct.some((c) => c.player === me) || Math.random() < 0.5) continue
    if (word && actions >= bot.skill) send({ kind: 'guess', text: word })
    else if (word && word.length >= 4 && Math.random() < 0.2) send({ kind: 'guess', text: word.slice(0, -1) })
    else send({ kind: 'guess', text: pick(WRONG) })
  }
  actions++
  await sleep(TICK_MS)
}

const names = new Map(host.state()?.players.map((p) => [p.id, p.name]))
for (const result of host.state()?.minigame?.results ?? []) console.log(`${names.get(result.playerId) ?? result.playerId}: ${result.points}`)
await sleep(RESULTS_MS)
stop()
```

If `tools/conn.ts`'s `Conn.frame()` is typed narrower than `MinigameFrame | null`, match how `tools/sim-ink.ts` narrows it (`frame?.role === 'player' && frame.id === 'ink'`).

A right guess scores 50 plus up to 50 more for time left; the drawer scores up
to 100 for how many got it. **Draw seconds** (default 80) sets the draw time and
**Drawers** limits the turns (0 = everyone once, so a short setlist block can
set 4). Words come from `packs/sketch-words.txt`, one per line; a match needs
three per connected player and never offers a word twice. Every moment has a
sound cue, placeholders for now.

`npm run sim-sketch` plays a match with eight bots against the running server;
