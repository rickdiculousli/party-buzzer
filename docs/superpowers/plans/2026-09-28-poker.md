# Poker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A no-limit Hold'em freezeout tournament as the fifth minigame: phones are gesture-driven felt tables, the board is the table the room watches, and a server restart resumes at the last hand.

**Architecture:** A pure, seeded engine under `server/minigames/poker/` (cards, evaluator, pots, equity, table) behind an untimed `MinigameDefinition`, like Phantom Ink. The runtime gains four small optional hooks (`checkpoint`, `resume`, `presence`, `hostStatus`) that other minigames don't implement. Client surfaces follow the Sketch pattern: a JSX-free `client/poker.ts` (cues, gestures, geometry) with tests, plus `PokerBoard.tsx` and `PokerPlayer.tsx`.

**Tech Stack:** Node (type stripping, `.ts` imports, no enums or parameter properties), `node:test`, Preact, existing interest kit (`fx-*`, `client/fx.tsx`), existing synth cues.

**Spec:** `docs/superpowers/specs/2026-09-28-poker-design.md`

## Global Constraints

- Minigame id `poker`, display name "Poker", `untimed: true`, `picksTeams: false`.
- Options: `stack` 1500 (100–100000), `bigBlind` 20 (2–10000), `levelMin` 10 (1–60), `shotSec` 30 (5–120).
- `STEP_MS` 50. All timing counts world ticks.
- No new dependencies. No score commit: every result has `points: 0`, `shots: 0`, and a `place`.
- Canon words: street, hand, match, peek, linger, table, "in the hand". Never round, hold, live, or stage for poker concepts.
- Writing: sentence case, no apologies, no exclamation marks. Zone copy: "↑ flick here to fold", "double tap to check" / "double tap to call N", "Mia to act".
- Interest kit only (design.md §4). The one new motion is the fold flight, built from a pure path function. Win % and clock numbers are cyan readouts with no effects.
- Room cues play on the board, personal cues on the owning phone. Placeholder recipes only; no existing tuned sound changes.
- Hole cards appear in no frame except the owner's until they are face up.

## Review Focus

1. **A player whose phone drops on their turn and never returns.** The 2 s disconnected clock acts for them every hand and the table keeps going until they bust. Task 4 test `disconnected seat is auto-acted within 2 s and blinds keep posting`.
2. **Stop mid-hand, then Start.** Chips already in the pot go back and every stack equals the hand-start checkpoint. Task 5 test `resume after a mid-hand stop restores hand-start stacks`.
3. **Two quick inputs from one phone** (a double tap then a flick, or a double tap sent twice with new seqs). The second is refused and changes nothing. Task 3 test `a second action after the turn passed is refused and changes nothing`.
4. **A hostile or buggy raise amount** (NaN, fractional, negative, below min, above stack). `classify` drops non-finite values, and `apply` refuses the rest as `invalid` or `not-allowed`. Task 6 test `malformed raise amounts are dropped or refused`.
5. **Three players down to two.** Heads-up blinds (button posts small blind, acts first preflop and last after) apply from the very next hand. Task 3 test `heads-up after a bust: button posts small blind and acts first preflop`.

### Task 3: The table: hands, streets, betting

**Files:**
- Create: `server/minigames/poker/types.ts`, `server/minigames/poker/table.ts`
- Modify: `shared/protocol.ts`: add `type ReactKind = 'nice' | 'ouch' | 'bluff' | 'wow'` and `REACT_LABEL: Record<ReactKind, string>` = Nice hand, Ouch, Bluff?, Wow
- Test: `server/minigames/poker/table.test.ts`

**Interfaces:**
- Consumes: Tasks 1–2.
- Produces (types.ts):
  ```ts
  type Street = 'preflop' | 'flop' | 'turn' | 'river'
  type Phase =
    | { at: 'deal'; until: number }                  // ticks
    | { at: 'bet' }
    | { at: 'reveal'; until: number }                // pause before the next street's cards
    | { at: 'runout'; until: number }
    | { at: 'showdown'; until: number }
    | { at: 'muck'; until: number; winner: PlayerId; shown: boolean }
    | { at: 'over' }
  type Seat = { player: PlayerId; stack: number; hole: [Card, Card] | null; bet: number; contributed: number;
    folded: boolean; acted: boolean; mayRaise: boolean; connected: boolean; faceUp: boolean }
  type FeedKind = 'blind' | 'fold' | 'check' | 'call' | 'bet' | 'raise' | 'allIn' | 'show' | 'win' | 'bust' | 'level'
  type FeedEntry = { id: number; player: PlayerId | null; kind: FeedKind; amount?: number;
    flick?: { dx: number; dy: number; speed: number }; auto?: true; hand?: string }
  type PokerWorld = { tick: number; seed: number; opts: { stack; bigBlind; levelMin; shotSec };
    seats: Seat[]; busted: { player: PlayerId; place: number }[]; button: number; handNo: number;
    elapsedBase: number; bb: number; sb: number; street: Street; board: Card[]; deck: Card[];
    actor: number | null; actBy: number | null; highBet: number; raiseSize: number;
    pots: Pot[]; showdown: { winners: PlayerId[]; name: string; five: Card[]; amount: number }[] | null;
    equity: Record<PlayerId, number> | null; feed: FeedEntry[]; nextFeedId: number;
    reactions: { id: number; player: PlayerId; kind: ReactKind }[]; lastReact: Record<PlayerId, number>;
    phase: Phase }
  ```
- Produces (table.ts):
  - `PACE = { dealMs: 1500, revealMs: 1200, runoutMs: 2500, showdownMs: 5000, muckMs: 4000, awayShotMs: 2000 }`
  - `createTable(seed: number, participants: PlayerId[], opts): PokerWorld`, with seats in `shuffle(mulberry32(seed), participants)` order, the button on a seeded seat, and hand 1 dealt
  - `type PokerAction = { kind: 'fold'; flick?: {dx;dy;speed} } | { kind: 'check' | 'call' | 'allIn' | 'show' } | { kind: 'raise'; to: number }`
  - `act(w: PokerWorld, player: PlayerId, a: PokerAction): InputOutcome`
  - `legal(w, player): { canCheck: boolean; call: number; canRaise: boolean; minTo: number; maxTo: number } | null`, null when it's not this player's turn
  - `stepTable(w: PokerWorld): void`, one tick
  - `inHand(w): Seat[]`

Rules to implement (from the spec):
- Hand start: move the button to the next seat that has chips. Heads-up, the button is the small blind. Post blinds (a short stack posts all-in). Deal two cards each from `handDeck(seed, handNo)`. Phase `deal`.
- Bet: preflop the first actor is left of the big blind (heads-up: the button). After preflop it's the first seat in the hand left of the button. `raiseSize` starts each street at `bb`.
- A full raise (increment ≥ `raiseSize`) sets `raiseSize = increment`, and every other seat still in with chips gets `acted = false, mayRaise = true`. A short all-in raises `highBet` only: others who owe get `acted = false` and keep `mayRaise`. `canRaise` requires `mayRaise` and a stack above the call.
- The street closes when every in-hand seat with chips has `acted && bet === highBet`. Then fold `bet` into `contributed`, rebuild `pots` with `buildPots`, and reset `acted` and `bet`.
- One seat left in the hand → award everything, then phase `muck`. Otherwise, if ≤1 seat can still bet → set `faceUp` on every in-hand seat, compute `equity`, and go to phase `runout`. Otherwise → `reveal`, then the next street. After the river → `showdown`: award each pot, record hand names and the five cards.
- Feed: append entries with rising `id` and keep the last 20. Blinds use `blind`, wins use `win` with `amount` and `hand` name.

- [ ] **Step 1: Write failing tests** (seeded, stepping with a `run(w, ms)` helper that calls `stepTable` `ms/50` times):
  - `blinds post and preflop action starts left of the big blind` (4 players)
  - `min raise: a raise below highBet + raiseSize is refused, all in is always allowed`
  - `a short all-in does not reopen betting`: a raises to 100, b goes all in for 150 total (short), c calls; a gets `legal().canRaise === false` and `call === 50`
  - `street closes when all have acted and matched; the next street starts left of the button`
  - `everyone folds to a raise: winner takes the pot and phase is muck; show sets faceUp`
  - `uncalled bet returns: all in for 500 against a 200 all in pays 300 back before showdown`
  - `showdown awards side pots to different winners` (fixed seed where a short stack wins the main pot)
  - `heads-up after a bust: button posts small blind and acts first preflop`, then acts last on the flop
  - `a second action after the turn passed is refused and changes nothing` (`JSON.stringify(w)` is unchanged)
  - `chips are conserved`: 6 random-legal bots with `mulberry32(9)` play 200 hands; after each hand start, the sum of stacks and contributions equals `6 * stack`
- [ ] **Step 2: Run** `node --test server/minigames/poker/table.test.ts`. Expected: FAIL.
