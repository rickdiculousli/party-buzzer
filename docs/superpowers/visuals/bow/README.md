# Bow visual index

**Status:** Rejected exploration. None of these files is an implementation
reference. They remain grouped here so the feedback history is understandable.

The mechanics-first build uses plain geometric placeholders. Future visual
work begins with one consistent direction for the full minigame before
returning to component studies.

## 01 — Component studies

Comparative SVG studies for the target, arrow, bow, target impact, and
arrow-on-arrow collision. Selection labels inside each sheet record the chosen
direction.

  grip correction.

  rejected.
